# petsocial-network

Соціальна мережа для домашніх тварин.

## Функціонал
- створення профілів тварин;
- публікація фото;
- лайки;
- коментарі;
- підписки.
## Встановлення
```bash
git clone https://github.com/VolodymyrP555/petsocial-network.git
cd petsocial-network
docker build -t petsocial .
docker run -p 3000:3000 petsocial
```
## Технології
- Node.js
- Docker
- GitHub Actions
